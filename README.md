# Datheon Machine Learning & Data Science Internship

Portfolio of three predictive modeling projects completed for the Datheon Machine Learning & Data Science Internship task pack. Each task directory includes its notebook, project documentation, and supporting data or figures.

## Projects

| Task | Project | Methods |
| --- | --- | --- |
| 1 | [Multi-Class Classification](task-1-multiclass-classification/) | Iris classification with Scikit-Learn, feature scaling, model benchmarking, and confusion-matrix visualizations |
| 2 | [California Housing Price Prediction](task-2-california-housing-price-prediction/) | Housing price regression, feature engineering, and regression model evaluation |
| 3 | [Customer Churn Classification](task-3-customer-churn-classification/) | Telco churn prediction with preprocessing, SMOTE, Random Forest, XGBoost, and ROC-AUC evaluation |

## Repository Structure

```text
task-1-multiclass-classification/
task-2-california-housing-price-prediction/
task-3-customer-churn-classification/
```

## Getting Started

Each project is self-contained. See its README for project-specific setup and instructions. Where a `requirements.txt` is provided:

```bash
python -m pip install -r requirements.txt
```

Open the project's Jupyter notebook to explore the data, run the modeling pipeline, and review its visualizations.

## Tools

Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-Learn. The churn project also uses XGBoost and imbalanced-learn.
